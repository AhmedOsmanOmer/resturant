PROJECT BRIEF
Single-page restaurant website for a web development course. Restaurant: Saffron & Olive, Mediterranean kitchen in Berlin.
Work in the current folder.
Files: index.html, css/style.css, README.md, .gitignore.
Plain HTML5 and CSS3 only. No JavaScript, no frameworks, no libraries. UTF-8, plain & and € characters.

REQUIREMENTS
- One h1 only (in the hero). Semantic landmarks: header, nav, main, section, article, footer, address.
- Nav links scroll to each section. Wrap inner content of header, sections and footer in a div.container.
- Sections: hero, about, menu (starters, mains, desserts, 4 dishes each with description and price), reservation, footer with opening hours, address and contact.
- Reservation is the main call to action: header button, hero button and a form section. The form needs no backend.
- box-sizing: border-box globally. Own CSS variables for all colors.
- Real use of Flexbox and real use of Grid.
- Mobile first. Breakpoints around 640px and 960px. No horizontal scroll at 360px, 768px and 1280px.
- No external images. Premium look with CSS only: deep warm dark, cream background, one gold accent, Playfair Display for headings and Inter for body (Google Fonts with Georgia and system fallbacks), generous spacing, subtle shadows, soft gradient hero, thin gold dividers, hover and focus-visible states.
- Realistic restaurant copy. No lorem ipsum, no emoji.

CODE STYLE
Clean, readable, beginner-friendly. No comments in HTML or CSS. Short simple class names (.hero, .menu-card, .menu-item, .price, .btn). No BEM, no utility classes, no unused classes or variables. 2-space indentation. CSS in the same order as the page.
